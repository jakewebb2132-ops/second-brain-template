# Second Brain Template

A private, portable memory system for AI tools. It gives Claude, Codex, Gemini, Cursor, and other file-aware assistants the same context about who you are, how you work, what you are building, and what has already been decided.

## Start here

1. Use **Use this template** or fork this repository.
2. Clone your copy as `~/brain`.
3. Follow [SETUP.md](SETUP.md).
4. Replace every placeholder before adding private information.

The useful version is plain Markdown and takes about 15 minutes. Supabase semantic memory is optional.

## Structure

```text
brain/
├── AGENTS.md
├── CONTEXT.md
├── SOUL.md
├── RULES.md
├── LEARNINGS.md
├── projects/INDEX.md
├── wiki/index.md
├── log/daily/
├── raw/
└── scripts/brain.py
```

## Privacy

Keep your personalized repository private. `.env` is ignored, but never commit credentials, private records, or secrets to a public repository.
